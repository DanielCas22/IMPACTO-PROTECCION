# IMPACTO PROTECCIÓN

Proyecto base para una tienda de protecciones para motociclistas con PHP, MySQL, HTML, CSS, Bootstrap 5 y JavaScript básico.

## Estructura inicial

- config/          -> configuración y conexión PDO
- database/        -> scripts SQL de base de datos
- includes/        -> header, footer y helpers reutilizables
- public/          -> páginas públicas de la tienda
- admin/           -> panel de administración y login
- assets/css/      -> estilos personalizados
- assets/js/       -> scripts básicos

## Siguiente paso

1. Crear la base de datos usando database/schema.sql.
2. Ajustar credenciales de conexión en config/database.php.
3. Probar el login administrativo en admin/login.php.
4. Continuar con el CRUD de productos en el próximo módulo.
